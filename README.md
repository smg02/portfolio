# BotPlayground Portfolio

Engineering portfolio of Mohammed Ghouse — Python Developer & Data Engineer.

## Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + Custom OKLab Theme Palette
- **Animations**: Motion (Framer Motion) + Interactive Micro-Interactions

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
